# Dependencies for the public demo deployment (DEMO_MODE=1).
#
# Deliberately NOT requirements.txt. The demo serves a frozen database and
# has no credentials, so it needs neither the Schwab SDK nor the Anthropic
# one -- and omitting them is the point, not an optimisation. DEMO_MODE
# removes /api/refresh and /api/chat, but a flag is one bad edit from being
# wrong; a machine where the SDKs are not installed cannot reach either
# service even if the gate failed open.
#
# tests/test_demo_mode.py::TestDemoNeedsNoCredentialedLibraries boots the app
# with both blocked, so a module-scope import that reintroduces them fails
# CI rather than a deploy.
#
# Also dropped: streamlit, plotly, matplotlib (the Streamlit-era UI, which
# the Next.js frontend replaced) and pynacl (only src/token_sync.py, which
# writes GitHub secrets).
